This entry sends exactly one word — the single word a grandma would text about AI: **"Aiiiii"**. It is the letters A-I themselves, stretched the way a grandma thumb-types a bewildered, delighted gasp at the robot grandchild: a typo she would actually make, warm and a little baffled, tied to AI by its very letters, and funny without a caption. The program writes that one word to `/output/entry.txt`, with a gate check that it is 1–30 characters, valid UTF-8, not only whitespace, and a single word.
